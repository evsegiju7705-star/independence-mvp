# INDEPENDENCE 0.3 — дополнение Memory Gym

Это автономная локальная страница-тренажёр для добавления в опубликованный PWA-проект INDEPENDENCE 0.2. Она не использует сервер, аккаунты, аналитику, внешние библиотеки или API. История сохраняется в localStorage браузера на устройстве.

## Что реализовано в этой первой версии дополнения
- Запомни последовательность: повторение последовательности цветов.
- Найди пары: карточки с шестью парами символов.
- Слова и ассоциации: запоминание шести слов и свободное воспроизведение.
- Локальная история результатов и её удаление.

Числовая цепочка и упражнение «Вспомни историю» оставлены для следующего небольшого обновления, чтобы сначала проверить базовый модуль на телефоне.

## Установка через Android

1. Скачай ZIP и распакуй его приложением «Файлы»/архиватором на телефоне.
2. Открой репозиторий `independence-mvp` на GitHub в Chrome. При необходимости включи «Версия для ПК».
3. В репозитории выбери **Add file → Upload files**.
4. Загрузи в корень репозитория три файла из этой папки: `memory-gym.html`, `memory-gym.js`, `memory-gym.css`. Не загружай ZIP как есть.
5. Нажми **Commit changes** и дождись обновления GitHub Pages.
6. Проверь страницу по адресу `https://ТВОЙ-ЛОГИН.github.io/independence-mvp/memory-gym.html`.
7. Чтобы открыть Memory Gym с главного экрана, добавь в `index.html` ссылку в подходящем месте:

```html
<a href="./memory-gym.html">Memory Gym</a>
```

Если пока не хочется редактировать главный экран, сохрани прямую ссылку на страницу в закладки браузера.

## Важное замечание о service worker

Если существующий service worker кэширует только заранее перечисленные файлы, страница Memory Gym всё равно должна открываться при наличии интернета, но для гарантированного офлайн-запуска добавь `memory-gym.html`, `memory-gym.js` и `memory-gym.css` в список precache в `sw.js`. Не заменяй весь `sw.js` этим дополнением: его текущая структура нам неизвестна.

## Приватность и ограничения
- Результаты пишутся в `localStorage` под ключом `independence.memoryGym.history.v1`.
- Данные не отправляются на сервер. Очистка данных сайта/браузера удалит локальную историю.
- Это упражнения для практики, а не медицинская диагностика и не клинически валидированный тест памяти.
- Страница использует существующий `index.html` как ссылку «назад».
