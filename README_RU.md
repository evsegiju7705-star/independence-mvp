# INDEPENDENCE 0.3.1 — Memory Gym

Обновлённый автономный модуль для существующего PWA INDEPENDENCE.

## В этой версии
- Последовательность цветов.
- Найди пары.
- Слова и ассоциации с таймером.
- Числовая цепочка с постепенным увеличением длины.
- Вспомни историю: короткий рассказ и вопросы на понимание деталей.
- История результатов хранится в `localStorage` на устройстве.

## Обновление через Android и GitHub
1. Распакуй архив.
2. Открой репозиторий `independence-mvp` в Chrome.
3. Открой **Add file → Upload files**.
4. Загрузи в корень репозитория файлы `memory-gym.html`, `memory-gym.js`, `memory-gym.css`, заменив старые версии.
5. Нажми **Commit changes**.
6. Открой `https://ТВОЙ-ЛОГИН.github.io/independence-mvp/memory-gym.html`.

Если страница была открыта ранее, обнови её принудительно или открой в новой вкладке. При необходимости очисти кэш только для этой страницы/сайта.

## Ссылка с главного экрана
Если кнопка Memory Gym ещё не добавлена, в `index.html` добавь ссылку в блок главного меню:
```html
<a href="./memory-gym.html">Memory Gym</a>
```
Не перезаписывай весь `index.html`: вставь только ссылку в подходящее место, сохранив текущий интерфейс.

## Офлайн-режим
Для гарантированного офлайн-открытия добавь три ресурса в массив precache существующего `sw.js`:
- `./memory-gym.html`
- `./memory-gym.css`
- `./memory-gym.js`

Не заменяй весь `sw.js`, пока не проверена его текущая версия. После изменения увеличь имя/версию кэша в существующем service worker, чтобы браузер получил обновление.

## Приватность
Модуль не использует сетевые API, внешние библиотеки, аналитику или аккаунты. История записывается в `localStorage` под ключом `independence.memoryGym.history.v1`. Очистка данных сайта в браузере удалит историю. Модуль не является медицинским тестом.
