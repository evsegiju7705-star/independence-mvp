# INDEPENDENCE — Android-first MVP 0.2

Это первый реально запускаемый прототип для ситуации, когда у разработчика есть только Android-смартфон. Это **PWA** — веб-приложение, которое можно установить на главный экран Android. Для первой версии не нужны Flutter, Android Studio, компьютер, сервер, аккаунт или платный API.

## Что уже работает

- Главный экран INDEPENDENCE.
- Режим Think First: ситуация → собственное мнение → возможные варианты.
- Сохранение размышлений локально в браузере Android.
- Удаление сохранённых размышлений.
- Добровольная двухминутная пауза.
- Переключение English, Русский, Deutsch, Français, Español.
- PWA-кэш для повторного запуска после первого открытия.
- Тесты переводов и базовой конфигурации.

В этой версии нет ИИ-чата, диагностики зависимости, фонового наблюдения или отправки личных записей в интернет. Счётчик показывает только число сохранённых размышлений, а не «уровень самостоятельности».

## Самый простой запуск на Android

### Вариант A — быстро проверить файл
1. Распакуйте ZIP на телефоне через приложение «Файлы».
2. Откройте `index.html` в браузере или HTML-редакторе, например Acode.
3. Проверьте переключение языка и создание размышления.

При открытии как локального файла установка PWA и офлайн-кэш могут не работать. Локальное сохранение зависит от браузера и способа открытия файла.

### Вариант B — установить как приложение (рекомендуется)
Для установки PWA нужен HTTPS-адрес. Бесплатный вариант — GitHub Pages.

1. Откройте `https://github.com` в Chrome и создайте бесплатный аккаунт, если его ещё нет.
2. Нажмите **New repository**. Название: `independence-mvp`. Выберите **Public** и создайте репозиторий.
3. На странице репозитория выберите **Add file → Upload files**.
4. Загрузите содержимое папки проекта: `index.html`, `app.js`, `manifest.webmanifest`, `sw.js`, `icons/`, `tests/`, `package.json`, `README_RU.md`.
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**.
7. В разделе **Build and deployment** выберите **Deploy from a branch**.
8. Branch: `main`; folder: `/ (root)`. Нажмите **Save**.
9. Подождите публикации и откройте адрес вида `https://ВАШ-ЛОГИН.github.io/independence-mvp/`.
10. В Chrome нажмите меню ⋮ → **Установить приложение** или **Добавить на главный экран**.

GitHub Pages публикует сайт публично. Сами записи пользователя остаются в localStorage браузера и не отправляются в репозиторий. Не вводите в прототип чувствительные сведения. Не публикуйте в репозитории пользовательские записи.

## Как пользоваться
1. Выберите язык в правом верхнем углу.
2. Нажмите **Think First / Сначала подумай**.
3. Заполните первые два поля; третье необязательно.
4. Нажмите «Сохранить».
5. Чтобы удалить записи, вернитесь на главный экран и выберите удаление.

## Как запускать тесты без компьютера
Тесты написаны для Node.js. На Android можно использовать Termux из F-Droid:
1. Установите Termux из F-Droid.
2. В Termux выполните `pkg update && pkg install nodejs`.
3. Перейдите в папку проекта (или клонируйте репозиторий командой `git clone https://github.com/ВАШ-ЛОГИН/independence-mvp.git`).
4. Выполните `npm test`.

Альтернатива: тесты можно запустить в бесплатной облачной среде Node.js, но для первого ручного испытания приложения это не обязательно.

## Ограничения и безопасность
- Это прототип, а не медицинский или психологический диагностический инструмент.
- Количество обращений к ИИ не используется для вывода о зависимости.
- Никакой фоновой слежки за экраном, приложениями или поведением.
- Записи хранятся в localStorage этого браузера. Очистка данных браузера может удалить их; резервной копии пока нет.
- GitHub Pages делает код публичным. Не помещайте туда приватные данные, пароли, ключи API или записи пользователя.
- Для международного запуска потребуются профессиональная редактура переводов, политика конфиденциальности, доступность и тестирование на реальных устройствах.

## Структура
- `index.html` — интерфейс и стили.
- `app.js` — логика, локализация, локальное сохранение.
- `manifest.webmanifest` — параметры установки PWA.
- `sw.js` — кэширование для офлайн-запуска.
- `icons/icon.svg` — иконка.
- `tests/app.test.js` — автоматические тесты Node.js.
